# Leaflet (vendorizado)

Biblioteca de mapa que roda no navegador. Guardada aqui dentro do projeto
(em vez de puxar da internet) pra a tela funcionar mesmo offline e não depender
de um servidor de terceiros.

- **Versão:** 1.9.4 (travada)
- **Origem:** https://unpkg.com/leaflet@1.9.4/dist/
- **Licença:** BSD-2-Clause (livre para este uso)
- **Baixado em:** 20/07/2026

Arquivos: `leaflet.js`, `leaflet.css`, `images/` (ícones do próprio Leaflet).
Para atualizar a versão, baixe os mesmos arquivos da versão nova e troque aqui.
